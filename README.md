Analyzed Indian job market data using Python, Pandas, and data visualization techniques to uncover hiring trends, salary patterns, experience requirements, and in-demand skills. Built an interactive Power BI dashboard with key insights on job demand, salaries, locations, experience, and top skills for data-driven decision making.
# 🇮🇳 Indian Job Market Analysis

## 📌 Overview

An end-to-end data analytics project analyzing Indian job market data to identify hiring trends, salary patterns, experience requirements, job locations, and in-demand skills.

The project uses Python for data cleaning and exploratory analysis and Power BI to create an interactive dashboard.

## 🎯 Objectives

- Analyze job market trends
- Identify the most demanded skills
- Analyze salary patterns
- Understand experience vs salary
- Identify top hiring locations
- Find high-demand job roles

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Power Query
- DAX

## 📊 Key Insights

- Data Analysis, SQL, Power BI, and Python are among the most demanded skills.
- Higher experience generally corresponds to higher salary.
- Salary varies substantially across experience levels.
- Bengaluru, Hyderabad, Gurugram, Pune, and Mumbai are major hiring hubs.
- Technical and analytical skills are highly relevant in data-related roles.

## 📈 Power BI Dashboard

The interactive dashboard provides insights into:

- Total Job Postings
- Top Demanded Skills
- Job Roles
- Average Salary
- Experience Distribution
- Experience vs Salary
- Top Hiring Locations
